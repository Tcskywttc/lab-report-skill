# 章节规则

已有教师模板：保留标题文字、顺序、目录和容器结构。正文顶层章节标题按用户已确认要求统一为宋体、加粗、四号（14 pt），详见 [排版规范](formatting-standard.md)；不因此增删编号或改变章节内标题层级。模板里的数据分析章节即使不适用，也不自动删除；可在正文注明不适用及原因。缺少模板要求的证据时标注待补。

没有教师模板时默认正文依次为：

1. 实验目的与要求（必需）
2. 方法、步骤（必需）
3. 实验过程及内容（必需）
4. 数据处理分析（条件必需）
5. 实验结论（必需）

仅数据处理分析可省略：存在定量测量、时序、统计、理论与实测对比，或教师明确要求时保留；单纯安装、配置且无定量分析任务时可以省略。省略后若使用连续章节编号应顺延，不留编号空洞。章节必需不等于可以编造内容；资料缺失写明确的待补项。

用户可明确指定其他结构。不要自行创建封面、教师评审页或目录。样例的模板大章节标签不带数字且以冒号结尾；内部采用“1 标题”“1.1 标题”的层级。

新写或补全报告时，将实验总览图默认放在“方法、步骤”开头的简短导语之后、详细步骤之前；已有教师模板时放入最靠前且语义适合的可编辑正文区域，不移动固定章节。若该处不适合插图，则放在“实验过程及内容”开头。总览图不是独立的固定大章节，也不要求固定页码。详细控制流与局部机制图放在对应解释附近，见 [流程图规范](flowchart-guide.md)。
