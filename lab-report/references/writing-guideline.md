# 实验思路与正文编写要求

只补用户需要的部分，不设置最低字数；优先保留用户原文和技术判断。仅要求排版时不执行扩写。

| 章节 | 检查问题 |
|---|---|
| 实验目的与要求 | 为什么做、掌握什么、验证什么？ |
| 方法、步骤 | 使用什么工具、如何完成、流程是什么？ |
| 实验过程及内容 | 实际做了什么、出现什么问题、如何处理、有什么证据？ |
| 数据处理分析（存在时） | 数据来源、计算过程、理论值、实测值、差异及原因是什么？ |
| 实验结论 | 完成什么、验证什么、达到什么程度、尚未覆盖什么？ |

这些是检查问题，不要求每次必须写“遇到问题”；没有已知故障就不虚构故障与解决经历。没有定量理论值时不强求误差分析。

## 实验思路必须详细展开

授权新写或补全正文时，对每个关键实验任务写清以下关系，融入教师模板现有章节，不机械增加固定小节：

1. **目标与输入**：该部分解决什么问题，输入数据、初始状态和必要环境是什么，期望观察什么输出。
2. **原理与方案**：采用什么模型、算法、公式或系统机制，关键变量表示什么；为什么这一方案适用于本实验，各阶段怎样衔接。选择理由必须有依据，不虚构比较试验。
3. **实现与关键代码**：按实际执行或数据流顺序说明关键处理；程序实验默认摘取影响结果的代码，解释输入输出、核心计算、状态变化与顺序、非直观设计及边界处理。源码说明“怎么做”，正文必须说明“为何这样做、与原理如何对应”。
4. **结果与验证**：交代操作或测试条件，指出图、表或日志中的具体变化，说明其支持什么结论；对照实验说明哪些条件保持不变、改变了什么。

“详细”以关键因果和复现条件完整为准，不要求逐行翻译、不堆大段源码、不凑字数。不能只写“调用某函数实现功能”“运行后效果良好”，也不能用总览图代替正文推理。若老师明确限制代码篇幅或禁止代码节选，遵循限制但仍解释实现原理；老师未要求代码分析不构成省略理由。纯配置或无源码实验则讲清关键配置、命令及其作用，不凭空添加程序。

交付前逐项核对：读者能否从正文理解关键输入如何得到输出、关键设计为什么成立、代码怎样落实原理、结果如何支持结论。任一关键环节只剩标题或笼统描述时先补全；材料不足时明确最小缺口，不编造细节。

## 原理、参数与程序实现

- 涉及算法或公式时，解释关键变量、单位、适用条件和公式在处理流程中的作用，并对应到实际程序步骤或关键函数。聚焦影响实验结果的关系，不要求逐式推导或逐行翻译代码。
- 关键参数说明取值、作用和选择依据，区分教师指定、理论计算、文档默认、经验选择和实际对比试验。代码能证明取值，不能单独证明选值理由；依据不明时标为待补，不把默认值写成“最优值”。
- 关键函数说明输入输出、核心处理及与实验目标的关系；对影响正确性的边界或异常情况，说明代码实际如何处理，区分已有处理与改进建议。需要代码注释时重点解释设计理由和非直观逻辑，不重复语法。报告整理不自动授权修改源代码。
- 代码节选来自实际源码，标明文件或函数；允许为版面断行、删去无关代码，但省略应明确且不得改变含义。代码前说明要解释的问题，代码后讲清运算、设计理由及验证联系，格式遵循 [关键代码排版](formatting-standard.md#关键代码排版用户确认的强制要求)。

## 报告内容与制作记录分开

报告呈现课程实验本身，不写“用了 computer-use 截图”“由 AI/Codex 生成”“截图已裁剪去除光晕”“按 skill 排版”“通过 Word COM 导出”等制作或验收过程，也不把这些写入图题、附录或实验心得。截图采集工具、原始像素、裁剪坐标、文档渲染记录等放在工作文件；影响交付的限制向用户单独说明。实验软件、开发环境、实际命令、测试条件、证据来源以及必要的“软件原生导出图”标识仍应如实保留。这不允许隐瞒实验数据的加工或虚构作者经历；用户或课程明确要求制作过程披露时遵循其要求。

## 问题分析与复测

有实际问题记录时，组织为“现象—原因或待验证假设—具体修改—复测效果”，引用相应日志、截图或数据；说明改了哪个参数、步骤或实现，以及修改前后发生了什么变化。未验证的原因保持为假设，未执行的修改保持为建议，尚未复测就说明效果未确认。无已知故障时不为补齐结构虚构排错经历。

## 结果与结论

- 将关键结论对应到图号、表格、日志或测量记录，并说明证据中哪些现象或数值支持判断。图题描述可观察的内容，图文对应与对照方式见 [截图规范](screenshot-guide.md)。
- 按实验目标选取有解释力的指标；耗时、定位成功率、角度误差等只是可选示例，不是每份报告的必填项。阈值通常是参数设置，单列阈值不能证明效果。纯配置或功能验证可使用明确的验收条件和实际输出，不强行加入无关量化指标。
- 有定量结果时交代测试条件、统计口径和数据来源，具体要求见 [证据规则](evidence-rule.md)。只有单次或有限样本时收窄结论，不概括为整体稳定、普遍准确或性能最优。
- 缺少支持关键结论的材料时，列出最小证据缺口或明确待补项；不为显得客观而填入未经测量的数据。不擅自添加“已熟练掌握”等个人感受，不反复索要封面信息。

以上检查融入教师模板的对应章节，不要求新增固定章节、额外篇幅或每项都写一段。
