# 实验截图规范

入稿要求是取得真实、清晰、无蓝色鼠标光晕或其他操作高亮的实验图，并在报告实际版面中读清关键文字。蓝色光晕即使位于边缘、没有盖住模型也不合格。截图用来证明什么，决定保留的范围；不以整屏或最高分辨率代替可读性验收。

## 截取方式与原图

- 需要证明软件界面、运行状态或操作结果时，采集对应真实窗口。只需展示波形、曲线或设计图时，可采用软件基于当前真实结果的原生导出，并在图题或正文注明“导出图”；教师要求界面截图时不能以导出图替代。
- 使用 computer-use 时，先按当前插件文档选择目标窗口并检查支持的接口。不要猜测 `hideCursor`、`dpi`、`scale` 等参数，也不要为取得更好看的截图绕过当前工具约束、调用未公开助手或修改全局鼠标设置。
- 入稿使用工具允许保存的原始截图文件或原始图像数据，优先无损 PNG。不要截聊天预览、缩略图或远程画面的二次截图。工具只提供预览或已缩小的图时，不能把它称为原生高清图；选择可用的合规导出方式或说明限制。
- 检查实际图像文件的像素尺寸，不将窗口逻辑坐标、预览显示尺寸或 DPI 标签当作原始像素。保留原图，裁剪和排版使用副本，并记录对应窗口／结果文件与图号，便于复核。
- 工具返回缩小预览时，先检查是否支持保存原始像素；也可在当前工具文档和权限允许的范围内，通过真实系统窗口截图或实验软件原生导出取得清晰结果，并检查实际文件。不得固定照搬某次 Windows 快捷键、画图程序或截图尺寸，不能把放大预览作为高清原图。

## 制作记录不得写进实验报告

computer-use 等采图工具、截图快捷键、粘贴保存过程、像素与裁剪记录、光晕处理、AI/Codex 或 skill 的使用情况属于报告制作记录，留在工作文件或面向用户的交付说明中。不得在报告正文、图题或附录写“本图通过 computer-use 采集”“已裁去蓝色光晕”等话语。报告只描述实验对象、条件、实际操作和可观察结果；软件原生导出仍应如实标为“导出图”，必要的数据处理方法也不能隐去。用户或课程明确要求披露制作过程时按其要求执行。

## 图号、参数与结果对照

- 图号、图题与正文引用保持一致；图题或相邻正文交代识别该结果所必需的输入样本、处理阶段和关键参数，可引用共用参数表，不必每张图重复全部设置。参数只能来自实际记录，缺失时标注待补，不补造到截图中。
- 用图片证明处理或修改效果时，优先展示同一样本、可比较条件下的前后结果，并标明“处理前／处理后”或对应阶段。保留可比较的显示范围、尺度与单位；条件不同则说明差异，不能只挑不同样本的有利结果作为改进证据。
- 正文指出图中具体可观察的变化及其支持的结论，不只写“效果良好”。单图只能支持其展示的结果，不能替代总体统计；只有一侧证据时如实说明，不拼造对照。
- 图题样式和连续编号遵循 [排版规范](formatting-standard.md)，不改写原始截图中的数值、标签或运行内容来满足标注要求。

## 鼠标、光晕与截取时机

- 区分普通系统鼠标指针、点击／定位光晕、悬停提示，以及实验软件的波形游标、十字线和选区。蓝色鼠标光晕及其他操作高亮必须从最终入稿范围中排除；实验软件的测量游标及其读数可能是证据，不能为“干净”一律消除。
- 先在原始截图中检查光晕是否真的存在。若仅操作预览显示，原始截图没有，就直接使用原图；不能仅凭预览判断截图被污染，也不能未经检查断言光晕来自某种工具。
- 在操作结束、结果渲染完整、临时提示消失后另取一张入稿图。短暂点击动画可稍候后重截；持续存在的鼠标高亮不会因等待必然消失。若工具支持安全移动指针，可移到不遮挡内容的位置；不支持移动时不要虚构 API，也不要通过点击结果区域来“移开鼠标”，以免改变状态。
- 只有当前截图工具明确提供排除指针选项时才使用；排除指针也不保证排除独立光晕层。优先选择当前工具支持的目标窗口截图并检查结果，不承诺任何捕获方式一定无光晕。
- 光晕或遮挡位于无关边缘时，可在保留必要上下文与可比较范围的前提下裁剪副本，必须确认最终入稿图中已完全排除。遮挡日志、数值、模型或波形时应重新采集。不能涂抹、克隆、AI 修复或重画被遮住的内容。
- 无法取得清晰且无光晕的图时，该图保持待补，继续完成其他已授权工作，并在交付说明中告知限制；不得以“未遮挡关键内容”为由把带光晕图当成合格成品。普通无光晕指针尽量移出画面，至少不得遮挡证据；此例外不适用于操作光晕。

## 清晰度与报告验收

- 截图前合理调整窗口、应用字号与内容范围，使关键信息占据足够面积。避免整块高分辨率桌面缩成报告中的小图；长日志、宽波形可采用总览加必要局部，保留文件名、信号名、时间轴、单位、命令或结果等解释上下文。
- 清晰度取决于原始像素和最终插图尺寸。有效 PPI = 图片像素宽度 ÷ 插图宽度（英寸）；约 12.4 cm 宽的图，1200～1500 px 可作为约 250～300 PPI 的采集参考，不是强制门槛。字太小即使像素多也难读，应调整内容或拆图；放大位图、改 DPI 标签、锐化不能恢复未采集的细节。
- 优先直接嵌入 PNG，保留纵横比，避免反复 JPEG 转存与额外下采样。仅在当前文档范围内处理图片压缩设置，不为本任务修改全局 Office 偏好或教师模板的共享样式。
- 两次验收：先检查原图的文字、数值、遮挡和上下文，再检查渲染后的报告在正常阅读尺寸下是否可读、是否裁切、图题是否对应。原图清楚而入稿模糊时，检查嵌入媒体、压缩与缩放；原图已模糊时回到采集环节。不能只看放大预览或只核对像素数便宣称“高清”。
- 放行前必须同时满足：原始证据真实、入稿范围无蓝色光晕及其他操作高亮、关键内容清晰完整、对照条件可比较、图题引用正确、正文没有采图工具与报告制作过程话语。缺一项就先修正，不以已完成截图数量代替质量检查。
