# DOCX 模板保护规则

## 区域边界

可编辑：用户指定的实验正文段落、正文中插图及其图题、结论、适用的数据分析。

人工处理：封面（包括姓名、学号、课程、教师、班级、日期等全部字段）、教师批阅意见、成绩评定、签字日期、评审和备注区。即使为空也保持原状，不填占位符。学校标识、模板说明和固定章节标签的文字及结构不改。正文顶层章节标签的字体、字号与粗细属于用户已明确授权的格式例外，按 [排版规范](formatting-standard.md) 统一为宋体、加粗、四号（14 pt）；在本次任务涉及的正文范围内局部修改，不扩展到人工处理区域。目录、页眉页脚和整体版式默认不改。

不能简单按整张表格划分权限：样例最后一张表同时包含可编辑的实验结论和不可编辑的教师区域。应识别到行、单元格及段落。不把“深圳大学学生实验报告用纸”这种正文标签误当真实页眉。

## 编辑策略

1. 保存教师原始模板，按 [目录管理规则](file-management.md) 识别唯一当前报告，确定工作副本和回退位置；验证后更新当前报告，不生成多个并列版本。识别模板固定区域和正文，不依据偶然页码或固定段落下标识别所有未来模板。
   输入为 `.doc` 时，先执行 [DOC 转换与保真检查](doc-conversion.md)。只有通过原件对照的转换副本才能作为底稿，不能把已失真的转换结果当成原模板。
2. 读取 styles、document、settings、relationships 及相关媒体；先解析有效格式，再修改。样例存在大量直接格式。
3. 保留表格网格、合并关系、宽度、边框、最小行高、分节、字段和关系。只更新目标段落或新增必要图片关系。不要全局替换段落、合并整份文档的 runs，或接受全部修订。
4. 正文采用局部段落/运行格式，或不影响保护区的新样式。禁止为统一正文而修改共享 Normal、主题或整个表格的字号。新增媒体不得替换保护区正在引用的资源。
5. 保护区保持文字、直接格式、继承样式和结构。正文变长可引发自然分页，但不能宣称评审区绝对页码或像素位置不变；若用户要求固定页位置，则另行确认篇幅约束。

## 验收

- 比较原件和副本的保护区域 XML 结构与文本（可规范化后比较），并检查其依赖的样式、页眉页脚、节属性和媒体关系。整个 document.xml 改变不等于保护区改变。
- 核对正文有效字体与段落属性，图题序号及正文引用，图片纵横比和单元格可用宽度。
- 渲染查看所有受影响页面，关注表格续页、文本裁切、过大空白、孤立标题、图题分离和图片可读性；字体缺失或未渲染时如实说明。
- 涉及格式转换时，须与原始文件在可正确显示它的原生应用中的表现对照；同一转换引擎的前后预览不能独立证明保真。保护区需由用户继续填写时，保留其可编辑性，整页图片不能算作等价替代。
- 若问题只能通过修改人工区域解决，先报告具体冲突，不借“修正一致性”越过范围。

有教师模板时以教师模板为默认。用户明确覆盖某项规则时无需再次询问已确认的同一事项；只在新的实质冲突或缺失信息阻止正确编辑时提问。
