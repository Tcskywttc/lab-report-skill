代码后说明：每个有效时钟沿只更新一次状态；计数序列包含 0 与 N，因此相邻翻转间隔为 N+1 个时钟周期；翻转两次才构成完整输出周期。进一步核对实际寄存器位宽是否容纳 N，以及复位后的初始输出。最后引用本次波形，比较相邻翻转时刻与理论间隔。没有实际代码或波形时，这些只作为写作示例，不能写成已实现、已验证的事实。

## 数据分析写法

若计数器从 0 到 N，且到达上限后的有效时钟沿使输出翻转，则相邻翻转间隔的理论值为 `(N+1) × Tclk`，完整输出周期为 `2(N+1) × Tclk`。N 是计数上限，Tclk 是时钟周期。代入本次实验确认的参数，再与本次波形证据比较；不得直接复用历史报告的具体时间值。
